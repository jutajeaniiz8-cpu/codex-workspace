# Sources

โฟลเดอร์นี้ใช้วางไฟล์งานที่ต้องการให้ Codex อ่าน ตรวจสอบ หรือสรุปด้วย Universal File Reader

ไฟล์ที่รองรับ เช่น PDF, DOCX, PPTX, XLSX/XLS, CSV/TSV, JSON, XML, HTML, TXT/Markdown, ZIP, รูปภาพ, เสียง และ EPUB

ข้อสำคัญ:
- ไม่ต้องคัดลอกไฟล์ระบบของ Skill มาไว้ที่นี่
- ให้วางเฉพาะไฟล์งานจริงที่ต้องการให้ Codex อ่าน
- ไฟล์ตัวอย่างในโฟลเดอร์นี้มีไว้สำหรับทดสอบ และสามารถลบหรือแทนที่ด้วยไฟล์งานจริงได้
